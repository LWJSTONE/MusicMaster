## 环境准备

### 1. 必须安装的软件

#### JDK 8 或以上（推荐 JDK 11）

**为什么需要？**
- Java 开发工具包，用于运行 Spring Boot 后端程序

**如何安装？**

1. **下载 JDK**
   - 访问 Oracle 官网：https://www.oracle.com/java/technologies/downloads/
   - 或者使用 OpenJDK（免费）：https://adoptium.net/
   - 选择对应你的操作系统版本下载

2. **安装 JDK**
   - Windows：双击下载的安装包，一路"下一步"完成安装
   - Mac：双击 .dmg 文件完成安装
   - Linux：解压文件到指定目录

3. **验证安装**
   - 打开命令行工具
   - 输入命令：
     ```bash
     java -version
     ```
   - 如果看到类似输出，说明安装成功：
     ```
     java version "11.0.15" 2022-04-19 LTS
     Java(TM) SE Runtime Environment 18.3 (build 11.0.15+8-LTS-111)
     ```

#### MySQL 8.0 或以上

**为什么需要？**
- 数据库软件，用于存储系统的所有数据

**如何安装？**

1. **下载 MySQL**
   - 访问官网：https://dev.mysql.com/downloads/mysql/
   - 选择对应的操作系统版本下载

2. **安装 MySQL**
   - Windows：
     - 双击下载的安装包
     - 选择"Developer Default"配置
     - 设置 root 用户的密码（请记住这个密码！）
     - 一路"Next"完成安装
   - Mac：
     - 下载 .dmg 文件，双击安装
     - 安装完成后会提示设置 root 密码
   - Linux：
     ```bash
     sudo apt-get install mysql-server  # Ubuntu/Debian
     sudo yum install mysql-server      # CentOS/RHEL
     ```

3. **验证安装**
   - 打开命令行，输入：
     ```bash
     mysql --version
     ```
   - 如果看到版本信息，说明安装成功

4. **启动 MySQL 服务**
   - Windows：服务会自动启动
   - Mac：
     ```bash
     sudo /usr/local/mysql/support-files/mysql.server start
     ```
   - Linux：
     ```bash
     sudo systemctl start mysql
     ```

#### Maven 3.6 或以上

**为什么需要？**
- Java 项目构建工具，用于打包和依赖管理

**如何安装？**

1. **下载 Maven**
   - 官网：https://maven.apache.org/download.cgi
   - 下载 apache-maven-3.8.x-bin.zip 或 tar.gz

2. **安装 Maven**
   - Windows：
     - 解压到 C:\Program Files\Maven
     - 配置环境变量：
       - 系统变量中添加 MAVEN_HOME，值为 Maven 解压路径
       - 在 Path 变量中添加 %MAVEN_HOME%\bin
   - Mac/Linux：
     ```bash
     tar -xzf apache-maven-3.8.6-bin.tar.gz
     sudo mv apache-maven-3.8.6 /usr/local/maven
     # 配置环境变量
     echo 'export PATH=/usr/local/maven/bin:$PATH' >> ~/.bash_profile
     source ~/.bash_profile
     ```

3. **验证安装**
   ```bash
   mvn -version
   ```

#### Node.js 16 或以上

**为什么需要？**
- JavaScript 运行环境，用于构建前端项目

**如何安装？**

1. **下载 Node.js**
   - 官网：https://nodejs.org/
   - 下载 LTS 版本（长期支持版本）

2. **安装 Node.js**
   - Windows：双击安装包，一路"Next"
   - Mac：双击 .pkg 文件安装
   - Linux：
     ```bash
     # Ubuntu/Debian
     curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
     sudo apt-get install -y nodejs
     ```

3. **验证安装**
   ```bash
   node -v
   npm -v
   ```

#### Git（可选，但推荐）

**为什么需要？**
- 版本控制工具，用于下载项目代码

**如何安装？**

1. **下载 Git**
   - Windows：https://git-scm.com/download/win
   - Mac：`xcode-select --install`
   - Linux：`sudo apt-get install git`

2. **验证安装**
   ```bash
   git --version
   ```

## 数据库配置

### 1. 创建数据库

**步骤：**

1. **登录 MySQL**
   ```bash
   mysql -u root -p
   ```
   - 输入之前设置的 root 密码

2. **创建数据库**
   ```sql
   CREATE DATABASE musicmaster DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. **验证数据库创建成功**
   ```sql
   SHOW DATABASES;
   ```
   - 应该能看到 musicmaster 数据库

4. **退出 MySQL**
   ```sql
   exit;
   ```

### 2. 导入数据库脚本

**步骤：**

1. **找到数据库脚本文件**
   - 文件位置：`backend/src/main/resources/sql/init.sql`

2. **导入脚本**
   ```bash
   mysql -u root -p musicmaster < backend/src/main/resources/sql/init.sql
   ```

3. **验证数据导入成功**
   ```bash
   mysql -u root -p musicmaster
   ```
   ```sql
   SHOW TABLES;
   ```
   - 应该能看到 6 张表：
     - user（用户表）
     - singer（歌手表）
     - song（歌曲表）
     - song_list（歌单表）
     - comment（评论表）
     - collect（收藏表）

### 3. 创建 MySQL 用户（可选，为了安全）

**如果不想使用 root 用户，可以创建一个专用用户：**

```sql
-- 创建用户
CREATE USER 'musicmaster'@'localhost' IDENTIFIED BY 'MusicMaster123!';

-- 授权
GRANT ALL PRIVILEGES ON musicmaster.* TO 'musicmaster'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;

-- 退出
exit;
```

## 后端部署

### 1. 修改配置文件

**找到配置文件：** `backend/src/main/resources/application.yml`

**需要修改的内容：**

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/musicmaster?useUnicode=true&characterEncoding=utf-8&useSSL=false&serverTimezone=Asia/Shanghai
    username: root  # 如果创建了专用用户，改为 'musicmaster'
    password: 你的MySQL密码  # 替换为实际的密码
    driver-class-name: com.mysql.cj.jdbc.Driver
```

**修改步骤：**

1. 使用文本编辑器打开 `backend/src/main/resources/application.yml`
2. 找到上述配置
3. 修改 username 和 password 为实际的数据库用户名和密码
4. 保存文件

### 2. 编译打包项目

**步骤：**

1. **进入后端目录**
   ```bash
   cd backend
   ```

2. **清理并编译**
   ```bash
   mvn clean install -DskipTests
   ```

3. **等待编译完成**
   - 第一次运行会下载依赖，可能需要几分钟
   - 看到 BUILD SUCCESS 说明编译成功

4. **查看打包文件**
   ```bash
   ls target
   ```
   - 应该能看到 `musicmaster-1.0.0.jar` 文件

### 3. 运行后端服务

**方式一：直接运行 JAR 包（推荐）**

```bash
java -jar target/musicmaster-1.0.0.jar
```

**方式二：使用 Maven 运行**

```bash
mvn spring-boot:run
```

**运行成功的标志：**

看到类似以下日志：
```
Tomcat started on port(s): 8080 (http) with context path ''
Started MusicMasterApplication in 5.234 seconds (JVM running for 6.123)
```

**测试后端服务：**

打开浏览器，访问：
- http://localhost:8080/api/user/page

如果返回 JSON 数据，说明后端运行成功！

## 常见问题

### 1. 后端启动失败

**问题：** 端口 8080 被占用

**解决方法：**

1. 查找占用端口的进程：
   - Windows：`netstat -ano | findstr :8080`
   - Mac/Linux：`lsof -i :8080`

2. 杀死进程或修改端口号

**修改端口号：**

编辑 `backend/src/main/resources/application.yml`：

```yaml
server:
  port: 8888  # 改为其他端口
```

### 2. 数据库连接失败

**问题：** 提示"Access denied for user 'root'@'localhost'"

**解决方法：**

1. 检查用户名和密码是否正确
2. 确保 MySQL 服务已启动
3. 检查防火墙设置

### 3. 前端无法访问后端 API

**问题：** 前端页面空白或报错

**解决方法：**

1. 确保后端服务已启动
2. 检查 `frontend/src/main.js` 中的 baseURL 是否正确
3. 打开浏览器开发者工具（F12），查看 Console 和 Network 标签的错误信息

### 4. npm install 失败

**问题：** 依赖下载失败或很慢

**解决方法：**

1. 切换到国内镜像源：
   ```bash
   npm config set registry https://registry.npmmirror.com
   ```

2. 删除 node_modules 和 package-lock.json，重新安装：
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

### 5. Maven 编译失败

**问题：** mvn clean install 报错

**解决方法：**

1. 检查 JDK 版本是否正确（JDK 8 或以上）
2. 清理 Maven 本地仓库缓存：
   ```bash
   rm -rf ~/.m2/repository  # Mac/Linux
   # 或删除 C:\Users\你的用户名\.m2\repository
   ```

3. 使用 -U 参数强制更新依赖：
   ```bash
   mvn clean install -U -DskipTests
   ```

### 6. 音乐无法播放

**问题：** 点击播放按钮没有反应

**解决方法：**

1. 检查歌曲 URL 是否有效
2. 确保音乐文件格式浏览器支持（推荐 mp3）
3. 检查浏览器的音频播放权限

### 7. 页面样式错乱

**问题：** 界面显示不正常

**解决方法：**

1. 清除浏览器缓存
2. 确保所有依赖都安装成功
3. 检查浏览器控制台是否有错误

## 部署到生产环境（可选）

### 1. 后端打包

```bash
cd backend
mvn clean package -DskipTests
```

生成的 JAR 包在 `target/musicmaster-1.0.0.jar`

### 2. 前端打包

```bash
cd frontend
npm run build
```

生成的静态文件在 `frontend/dist` 目录

### 3. 使用 Nginx 部署

1. 安装 Nginx
2. 将前端 dist 目录内容复制到 Nginx 的 html 目录
3. 配置 Nginx 反向代理后端接口：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

4. 启动 Nginx：
   ```bash
   sudo nginx -t  # 测试配置
   sudo systemctl start nginx
   ```
